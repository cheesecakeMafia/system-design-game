### How This Project Uses It

The System Design Primer serves as the course textbook. Every lecture assigns pre-reading sections from it, and Boss Battle exercises reference its system design solutions. The primer is cloned into `deps/system-design-primer/` by the setup script and is not included directly in this repository.

## Server Survival

- **Author:** Kostyantyn Pshenychnyy (pshenok)
- **Repository:** [github.com/pshenok/server-survival](https://github.com/pshenok/server-survival)
- **License:** MIT

### How This Project Uses It

Server Survival is a Three.js browser game where players build cloud infrastructure to handle traffic. The course uses it as a gamified learning tool at specific integration points — students play the game to reinforce system design concepts they've learned in lectures. The game is cloned into `deps/server-survival/` by the setup script and is not included directly in this repository.
